---
description: Show where the Monkey Kitchen view is running
---

Find the line in your session context that starts with "The live kitchen view is at" and give the user that address exactly as written (for example http://localhost:4747). It is a plain address with no key in it: tell them to open it in their browser, that nothing needs unlocking, and that the server starts by itself when a session starts.

If your session context has no such line (or it says the kitchen view is off, or that another server is in the way), tell the user what that line says instead, or, when there is none, to start a new Claude Code session. Do not guess an address and do not do anything else.
